# ToDo List

This is a simple web-based ToDo list application. It allows you to add and remove tasks. Tasks are persisted in the browser's local storage.

## Usage

Open `index.html` in your browser. Enter a task in the input box and click **Add**. Your tasks will appear in the list below. Click **Delete** to remove a task.

### Running locally

If you have Node.js installed, you can start a quick server with:

```bash
npx serve
```

Then open the provided URL in your browser to use the app.
